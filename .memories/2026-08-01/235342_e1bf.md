## Drift audit: deployed Supabase MCPs vs local repo

**WHAT:** Compared all 6 deployed Supabase Edge Functions and the live DB schema against local `kae36/personal` HEAD.

**METHOD:** `supabase functions download --use-api` to pull actual deployed source (no docker needed), diffed against local files. Used the Supabase Management API (`/v1/projects/{ref}/database/query`, CLI's stored access token) to query `information_schema` and `pg_get_functiondef` for the live DB, since `supabase db dump` requires docker (unavailable here).

**FINDINGS:**
- `open-brain-mcp` (core) is **STALE**: deployed bundle byte-matches commit `1f3289a` (2026-03-30). Local `server/index.ts` is 2 commits ahead, never redeployed:
  - `6eb0380` "Improve ChatGPT MCP compatibility" (adds `search`/`fetch` tools)
  - `a42695f` "[server] Return JSON-RPC error envelopes on auth failure" (also carries the `annotations` blocks — `readOnlyHint`/`destructiveHint`/etc. — on every tool)
  - Last actually redeployed 2026-04-17 (secret-rotation redeploy only, no code change since).
- `household-knowledge-mcp`, `home-maintenance-mcp`, `family-calendar-mcp`, `meal-planning-mcp`, `delete-thought-mcp`: all byte-match local HEAD exactly. No drift.
- DB schema: no drift. Live `thoughts` table has exactly the 7 documented columns (incl. `content_fingerprint`), and live `upsert_thought()` body matches `docs/01-getting-started.md` Step 2.6 exactly. Optional `thought_audit` schema not installed (expected — opt-in).
- Fork publish gap: local `kae36/personal` is 1 commit ahead of `origin` (unpushed `fd8da21`). Separately, `delete-thought-mcp`'s 4 files are staged but never committed — so that integration is live in Supabase while absent from git history entirely (inverse of the server's problem: server is ahead in git but behind in prod).

**IMPACT:** Explains part of the earlier delete_thought investigation — the deployed `capture_thought` also has no `annotations` block (matches `delete_thought`'s lack of one), because the whole deployed server predates that commit. Not a tool-specific inconsistency, a stale-deploy issue.

**NEXT:** Redeploy `open-brain-mcp` from current HEAD to pick up ChatGPT compat tools + JSON-RPC auth envelope + annotations. Commit + push the staged `delete-thought-mcp` files so git history matches what's actually live.
