## enhanced-mcp is deployed and connected (after a rejected access key was fixed)

**WHAT**
- The `open-brain-enhanced` MCP server (user-scoped HTTP server, `https://dpcybjkruqrbdlyvfeqb.supabase.co/functions/v1/enhanced-mcp`, `x-brain-key` header) failed to connect at session start with "Dynamic Client Registration rejected (HTTP 404): requested path is invalid".
- The user replaced the access key, ran `/mcp` reconnect, and it now connects. All 13 tools are available. Verified with a read-only `brain_thought_stats` call: 799 thoughts total, 721 with `type: null`, 50 reference, 14 observation, 12 task, 2 idea.

**WHY it failed (root cause)**
- The function was already deployed and reachable. It returned `401 {"error":"Invalid or missing access key"}` (from `integrations/enhanced-mcp/index.ts`) for the key in `~/.claude.json`, sent as `x-brain-key` and as `Authorization: Bearer`. The key itself was well-formed (64 lowercase hex, no whitespace), so the deployed `MCP_ACCESS_KEY` secret simply differed from it.
- Claude Code treats a 401 as "server needs OAuth", probes `/register`, and gets a 404. So the DCR 404 was a side effect, not a routing or deploy problem.
- The user first tried the value from `supabase secrets list`. That command only shows a SHA-256 digest of each secret, never the value, so a digest can never work as a key. The user then located the real key and reconnected.

**HOW it was diagnosed**
- Read the server entry from `~/.claude.json` with secrets redacted, probed the endpoint with curl with and without the key, and read the auth code path. Nothing in the repo or client config was changed; the fix was entirely the user's key correction.

**IMPACT**
- Advances the "Next capability: enhanced-mcp" item in the active brief from "chosen, not started" to deployed and connected. It needed `MCP_ACCESS_KEY` and `OPENROUTER_API_KEY` as function secrets, both set at the console by the user.
- `MCP_ACCESS_KEY` is a project-wide secret, so rotating it would also affect any stock function that reads the same name. Reuse the existing key rather than rotating it blindly.
- Bash sandbox also failed to start this session (seccomp / nested userns error), so read-only checks ran unsandboxed.

**Lesson**
- A 401 from an HTTP MCP server surfaces in Claude Code as a confusing DCR 404. When that appears, probe the endpoint directly before suspecting routing or deploy.
